# Lemuel Jan Suico — Personal Portfolio

A production-focused personal portfolio built with React and TypeScript, designed around a modern Spider-Man-inspired visual identity. The project combines strong frontend engineering, responsive UI design, interactive experiences, and a carefully structured component architecture to present my work, technical capabilities, and professional profile.

## Overview

This portfolio is more than a static personal website. It is an interactive frontend application designed to demonstrate how I approach modern web development, from component architecture and responsive interfaces to performance, maintainability, and user experience.

The visual direction takes inspiration from Spider-Man through cinematic transitions, web-inspired interactions, comic-book aesthetics, and a dark, high-contrast interface while maintaining a professional and polished presentation.

## Architecture

The application follows a modular React architecture where interfaces are composed from reusable components rather than being implemented as a single monolithic page.

Typical responsibilities are separated into:

* UI components
* Page sections
* Data/configuration
* Assets
* Styling
* Interactive behavior
* External service integrations

This approach makes the application easier to extend and maintain as additional projects, technologies, and portfolio sections are introduced.

## Getting Started

### Prerequisites

Make sure the following are installed:

* Node.js
* npm
* Git

### Installation

Clone the repository:

```bash
git clone <repository-url>
cd <project-directory>
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will then be available through the local development URL provided by Vite.

### Production Build

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
